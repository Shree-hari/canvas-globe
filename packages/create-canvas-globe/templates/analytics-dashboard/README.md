# CanvasGlobe analytics dashboard starter

A responsive Vite starter for dense geographic demand, incident, and revenue data. It includes
interactive hex bins, a live ranking, summary metrics, legends, and globe or Natural Earth map views.

```bash
npm install
npm run dev
```

Replace the sample arrays in `src/main.js` with your own coordinates and values.

Before production use, purchase a CanvasGlobe license at
https://canvasglobe.swiftools.com/pricing and add the supplied license key to the `licenseKey` option.
