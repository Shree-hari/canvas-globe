# CanvasGlobe logistics routes starter

A responsive Vite starter for shipment routes, freight operations, traffic, and network activity. It
includes animated great-circle arcs, live arrival pings, route filters, operational cards, and globe
or flat-map views.

```bash
npm install
npm run dev
```

Replace `hubs` and `routes` in `src/main.js` with your own network data.

Before production use, purchase a CanvasGlobe license at
https://canvasglobe.swiftools.com/pricing and add the supplied license key to the `licenseKey` option.
