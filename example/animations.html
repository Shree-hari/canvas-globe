Animation catalogue

Every effect below is running live on canvas-globe - no WebGL, no video. Each one is built to survive record() as a seamless loop, which is what a Canva or Adobe Express add-on actually ships. Click a card to pick it, then send me the letters.

Picked: none

Reading the badges

  • built-in already in the package - an add-on can ship it today.
  • extend possible now through onRender / renderMarker, but should become a first-class option.
  • engine needs new rendering work inside the library.

Why these and not others

I left out anything that needs a GPU (volumetric clouds, real atmospheric scattering, depth-of-field) and anything that cannot loop cleanly. Marketplace buyers judge a pack by its thumbnail loop, so an effect that only looks right once is worth very little.
