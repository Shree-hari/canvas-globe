# CanvasGlobe support

## Product support

For installation help, licensing questions, commercial inquiries, or general
support, email [globe@swiftools.com](mailto:globe@swiftools.com).

Use GitHub issues for reproducible bugs, documentation corrections, and public
feature requests. Search existing issues before opening a new one and use the
matching issue form so maintainers receive the information needed to respond.

Do not post license keys, customer data, precise user locations, private source
code, or security details in a public issue.

## Security

Report vulnerabilities through GitHub private vulnerability reporting. Follow
[SECURITY.md](SECURITY.md) for the information to include.

## Commercial work

Commercial license questions and separately scoped implementation work can be
sent to [globe@swiftools.com](mailto:globe@swiftools.com). Commercial support
does not replace the terms of the applicable order and agreement.
