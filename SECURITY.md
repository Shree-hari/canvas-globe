# Security policy

## Supported versions

Before the first stable release, only the latest published version is
supported. After `1.0.0`, this table must be updated with the maintained major
versions.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting / Security Advisory flow for the
public `Shree-hari/canvas-globe` repository. Do not open a public issue with
exploit details or customer information.

Include:

- affected version and import path;
- browser and framework, if relevant;
- minimal reproduction steps;
- expected and observed impact; and
- whether the issue is already public.

The project will acknowledge a valid report as capacity permits. No response
time or bounty is promised unless separately agreed in writing.

CanvasGlobe has no runtime dependencies, API keys, server component, telemetry,
or required network calls. Reports about documentation-site dependencies
should identify that scope separately.
