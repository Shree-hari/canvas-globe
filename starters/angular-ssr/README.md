# CanvasGlobe Angular SSR starter

This starter uses Angular's application builder, server rendering, prerendering
and client hydration. `CanvasGlobeComponent` leaves a stable canvas shell in
the server output and creates the interactive renderer in the browser.

```bash
npm install
npm run dev
```

Create a production SSR/prerender build with:

```bash
npm run build
```

CanvasGlobe requires a commercial license for production use. See
https://canvasglobe.swiftools.com/pricing.
