# CanvasGlobe choropleth analytics starter

A responsive Vite starter for market comparisons, elections, coverage, adoption, and country-level
analytics. It includes three switchable metrics, a live ranking, country selection, a continuous
legend, and globe or Natural Earth map views.

```bash
npm install
npm run dev
```

Replace `metrics` and `countries` in `src/main.js` with your own country-code dataset.

Before production use, purchase a CanvasGlobe license at
https://canvasglobe.swiftools.com/pricing and add the supplied license key to the `licenseKey` option.
