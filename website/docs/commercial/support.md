# Support and custom work

## Community support

Use GitHub issues for reproducible bugs and public feature requests. Include a
minimal example, package version, browser, and expected versus observed result.

Never put customer data, precise user locations, license keys, or vulnerability
details in a public issue. Report security concerns through GitHub's private
Security Advisory flow.

## Commercial support

Solo and Team plans include standard support for 12 months. Business receives
priority support. Support covers documented CanvasGlobe APIs and confirmed
library defects; it does not include guaranteed response times or debugging an
unrelated application unless an order says otherwise.

## Custom work

Paid implementation can be scoped separately for:

- custom visual treatments and branded scenes;
- framework or design-system integration;
- large-data performance work;
- custom projections or geographic data;
- accessibility review;
- export/video workflows; and
- OEM or builder integration.

Commercial contact remains disabled until a private monitored route and seller
identity are configured. Do not post confidential procurement details publicly.
