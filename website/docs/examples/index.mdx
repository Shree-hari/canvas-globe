# Examples

Every example below is a **real job someone is trying to do** — put a globe in a hero, prove that
customers exist, show where the team is, generate a share card — not a feature demo dressed up as
one. Each page has a live globe you can poke at, the complete code, and a short note on *why* the
choices were made, because a map that looks impressive and communicates nothing is a waste of a
fold.

## The rules these follow

**A globe must earn its pixels.** If the same message survives as a sentence, use the sentence. The
globe is worth it when *spread* is the point — many places, far apart, at once.

**Real numbers only.** Every one of these can be driven from a live source. Inventing signups to
make a map look busy is the fastest way to lose the trust the map was supposed to build.

**It has to work on a phone.** Half your traffic will see this at 380 px wide with one thumb. Every
example here degrades to something legible, and most of them are readable with motion switched off
— the library honours `prefers-reduced-motion` by default.

**Nothing leaves the browser.** No tiles, no API keys, no request per pageview, no third-party
script in your consent banner. That is not a marketing claim, it is why the bundle is 120 KB.
