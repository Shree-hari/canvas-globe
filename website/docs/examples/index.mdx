# Examples

:::note Demonstration data
People, companies, customer counts, revenue, and activity shown in these
examples are fictional unless a page explicitly cites a real source. They
demonstrate product patterns, not CanvasGlobe customer proof.
:::

Every example below is a **real job someone is trying to do**: put a globe in a hero, prove that
customers exist, show where the team is, generate a share card: not a feature demo dressed up as
one. Each page has a live globe you can poke at, the complete code, and a short note on *why* the
choices were made, because a map that looks impressive and communicates nothing is a waste of a
fold.

## Selection criteria

Use a globe when geographic distribution is part of the message. Use text when
the same information is clearer as a sentence.

Use real data. Do not invent signups or activity to make a map look busy.

Test the map at mobile widths and with motion disabled. CanvasGlobe honours
`prefers-reduced-motion` by default.

CanvasGlobe does not request tiles or require API keys. Its geographic data is
included in the package.
